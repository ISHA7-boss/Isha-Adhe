ISHA ADHE — PORTFOLIO WEBSITE

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the isha-portfolio folder.
3. Double-click index.html to open it in a browser.

BEFORE PUBLISHING — PERSONALIZE THESE ITEMS
1. In index.html, replace YOUR_EMAIL@example.com with your email address.
2. Replace the LinkedIn and GitHub homepage links with your profile URLs.
3. Add your resume PDF and link it to a Download Resume button if desired.
4. Add project photos, GitHub repositories and demos when available.
5. Add the Microsoft certificate PDF if you want visitors to open it.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to GitHub.
2. Create a public repository named isha-portfolio.
3. Upload all files and the certificates folder, keeping the folder structure.
4. Open repository Settings > Pages.
5. Choose Deploy from a branch, select main and /(root), then Save.

Built with HTML, CSS and JavaScript. No build tools required.
